# 90-Day Full-Stack Development Journey 🚀

This repository documents my 90-day journey of building a full-stack web application from scratch.

## Roadmap

### Month 1 — Frontend
- React
- JSX
- Components
- Props
- State
- Conditional Rendering
- API Calls
- Advanced React Concepts

### Month 2 — Backend
- Node.js
- Express.js
- REST APIs
- Middleware
- MongoDB
- PostgreSQL
- Authentication
- Email Services
- Deployment
- Nginx

### Month 3 — Advanced Features
- WebSockets
- AI / GPT integration
- Advanced application features
- Performance improvements
- Final deployment

The goal is to build, learn, and document something every day.
